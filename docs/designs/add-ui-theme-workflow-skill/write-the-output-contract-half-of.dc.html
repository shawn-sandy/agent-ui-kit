STEP 8 · WHAT THE SKILL WRITES INTO A PROJECT
Anatomy of the emitted block
appended to the project's token stylesheet
/* auk theme: binds project tokens */
:root {
--auk-button-bg: var(--color-primary);
--auk-tabs-selected-tab-color: var(--color-primary);
--auk-dialog-color: var(--color-text);
--auk-button-radius: var(--radius-md);
--auk-alert-error-color: #b91c1c; /* no token — literal kept */
}
[data-theme="dark"] { /* the project's own selector, verbatim */
--auk-dialog-backdrop-bg: var(--overlay-dark);
/* only tokens that change under dark */
}
Project token → no fallback
If the token is later removed, the property goes invalid and the component's own var(--auk-*, literal) wins. Asserted in step 10, not trusted.
Brand-bearing only
Never a size, spacing, duration or placement property. Never a forced-colors query — high-contrast settings stay the user's.
Guard: no auk components yet
No stylesheet contains an auk- selector → the skill says so, points at the component skills, and emits nothing.
After emitting: re-measure
Contrast and focus visibility are re-checked by the named e2e specs. A failing brand value is reported and asked about — never silently reverted.

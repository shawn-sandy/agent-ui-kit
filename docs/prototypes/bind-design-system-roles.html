The chain, live

Each button reads var(--auk-button-bg, #1a56db). The generated roles file chains that to --auk-role-primary on :root, and a binding chains the role to your token. Remove the primary binding and the button falls back to the shipped blue: an unbound role is invalid at computed-value time, so the literal applies. A custom property resolves where it is declared, so a role set on a lower element (the Acme wrapper) is never seen by the root chain: a block below the root must restate the chain lines for the roles it sets, and this page adds them for you. The stylesheet it builds is shown in the readout.

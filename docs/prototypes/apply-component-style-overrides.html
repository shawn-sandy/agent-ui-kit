Try it: every override below is applied to this real auk button

Three doors. A root, ancestor or element override sets a --auk-button-* custom property at that scope. A rule override writes a plain .auk-button { … } rule into a stylesheet that loads before the component styles and sits outside any layer. With the shipped CSS wrapped in @layer auk, that early plain rule still wins. Untick the first box to see today's behaviour, where it loses to the component's own later rule. The catch: a layer ranks below every unlayered rule, including this page's own reset, * { padding: 0 }. Here that reset sits in a reset layer ordered before auk. Untick the second box to leave it unlayered, as most projects do, and watch it strip the layered button's padding.
